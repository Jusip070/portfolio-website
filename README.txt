JOSEPH PINEDA — PORTFOLIO WEBSITE
================================

FILES
- index.html  : website content and sections
- style.css   : responsive layout, visual styling, and animations
- script.js   : scroll reveal, active navigation, mobile menu, cursor glow, parallax

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For best results, use Chrome, Edge, or Firefox with an internet connection
   (Google Fonts are loaded online).

CUSTOMIZE BEFORE PUBLISHING
- Replace the portrait placeholder in the About section with your photo.
- Replace Certificate Title One–Five with your real certificate names,
  issuers, dates, and certificate links.
- Replace your.email@example.com with your actual email address.
- Replace the # links on LinkedIn, GitHub, and Facebook with your profile URLs.
- Add real project screenshots, descriptions, and live project links as available.

FRAMER NOTE
This is a standalone HTML/CSS/JavaScript website package, not a native .framer
project file. You can use it as a working website, deploy it with a static host,
or use its layout and styling as a reference while rebuilding it in Framer.
